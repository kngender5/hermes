# Siteringsregler — Kildekompasset og IEEE i Tekst

## Grunnleggende IEEE-sitatrekkja

Henvisninger i løpende tekst bruker numeriske klammeparenteser `[#]`, plassert **før** tegnsetting:

```
...i henhold til FEL [1, § 16].
...som spesifisert i NEK 400 [2, s. 142].
...som dokumentert i sluttkontrollen [2, s. 142].
```

## Referanseliste — Kronologisk, Ikke Alfabetisk

Referansene ordnes etter første forekomst i teksten, ikke alfabetisk.

### Mal for Elektroniske Forskrifter (Lovdata)
```
[N] *Tittel på forskrift*, år. [Online]. Available: URL
```
Eksempel:
```
[1] *Forskrift om elektriske lavspenningsanlegg*, 2001. [Online]. Available: https://lovdata.no/dokument/SF/forskrift/2001-12-14-1515
```

### Mal for Offisielle Standarder
```
[N] *Tittel*, NUMMER:år, år. Hentet fra: URL
```
Eksempel:
```
[4] *Elektriske lavspenningsanlegg*, NEK 400:2022, 2022. Hentet fra: https://www.nek.no/
```

### Mal for Universitetsressurser (Canvas)
```
[N] Institusjon. «Kursnavn og kommentar.» Nettside. URL (accessed MANTH ÅR)
```
Eksempel:
```
[6] UiT Norges arktiske universitet. «Kursplan og laboppgaver for automasjonsteknikk.» Canvas. https://canvas.uit.no (accessed mai 24, 2026)
```

### Mal for Audiovisuelle Medier (Panopto / Zoom)
```
[N] Fornavn Etternavn, «Forelesningstittel,» KURSKODE Fagnavn, Institusjon, videoopptak på Plattform, DATO.
```
Eksempel:
```
[7] T. Hansen, «Funksjonell sikkerhet og PL-beregninger i robotceller,» AUT-3001 Automasjon, UiT, videoopptak på Panopto, mars 12, 2026.
```

## URL-Regel (Kildekompasset)

En URL i referanselisten skal **ALDRI** avsluttes med punktum. Punktum kan forveksles med en del av nettadressen og skape en død lenke.

**Korrekt:**
```
[1] *Forskrift ...*, 2001. [Online]. Available: https://lovdata.no/dokument/SF/forskrift/2001-12-14-1515
```

**Feil:**
```
[1] *Forskrift ...*, 2001. [Online]. Available: https://lovdata.no/dokument/SF/forskrift/2001-12-14-1515.
```
