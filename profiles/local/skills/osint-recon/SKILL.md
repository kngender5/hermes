# Norwegian registry review

Use the canonical `skills/osint-recon/SKILL.md` and its bundled CLI from the Hermes checkout. Start with supplied public organisation, municipal or .no registration records. A fresh-record plan is an operator review item only. This profile performs no external queries, installs no collection tools, and does not expose a live or active fallback.

If the canonical skill and scripts are unavailable, stop with a setup error. Preserve source provenance and unresolved conflicts. Escalate logged or sensitive sources to a human without submitting the query, and stop on prohibited lookups.
